# سَنَد | SANAD

منصة مصرية رقمية تهدف إلى تسهيل الوصول إلى الخدمات والمعلومات الموثوقة في مكان واحد.

## الحالة الحالية
النسخة الأولى من واجهة المستخدم (Frontend prototype) قيد التطوير. البيانات المعروضة تجريبية وليست معلومات حكومية معتمدة.

## التقنيات
- React + TypeScript
- Vite
- CSS responsive
- Lucide icons

## التشغيل محليًا
```bash
npm install
npm run dev
```

## البناء
```bash
npm run build
```

## مبادئ أساسية
- العربية واتجاه RTL افتراضيًا.
- البحث والتصفح دون اشتراط إنشاء حساب.
- عرض تفاصيل الخدمة داخل سَنَد، بما فيها قنوات التقديم الإلكترونية والرسمية عند التحقق منها.
- عدم نشر روابط أو معلومات حكومية قبل مراجعة مصادرها.
- مراعاة سهولة الوصول واختلاف احتياجات المستخدمين.

## خارطة الطريق
1. واجهة رئيسية وتنقل بين الأقسام وتفاصيل الخدمة.
2. تصميم نموذج بيانات الخدمات ومصادرها.
3. بحث عربي أذكى.
4. لوحة إدارة لمراجعة المعلومات وتحديثها.
5. حسابات ومزامنة ومزايا PWA.
