# سَنَد | SANAD

منصة مصرية رقمية تساعد المواطنين على فهم احتياجاتهم والوصول إلى الخدمات والمعلومات والفرص من مصادرها الرسمية.

## الأقسام
- الخدمات الحكومية
- التعليم
- المساعدات والدعم
- ذوو الإعاقة وكبار السن
- الفرص والمبادرات
- دعم المشروعات الصغيرة

## التقنيات
- Frontend: React + Vite + JavaScript + CSS
- Backend: Python + FastAPI
- Database: SQLite + SQLAlchemy
- Icons: Lucide React

## تشغيل الواجهة محليًا
من مجلد المشروع:
```powershell
npm.cmd install
npm.cmd run dev
```

## تشغيل الباك إند
من مجلد المشروع:
```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn main:app --reload
```

توثيق API متاح على: http://127.0.0.1:8000/docs

## إضافة الدفعة الأولية من الخدمات
بعد سحب آخر تحديثات GitHub، ومن داخل مجلد المشروع:
```powershell
cd backend
.\.venv\Scripts\python.exe seed_services.py
```

- يضيف ملف التهيئة 150 سجلًا موزعة بالتساوي على الأقسام الستة (25 لكل قسم).
- كل السجلات تُضاف بحالة **مسودة (draft)** ولا تظهر للزوار قبل مراجعتها ونشرها من لوحة الإدارة.
- السكربت آمن لإعادة التشغيل؛ يتجاوز الخدمة الموجودة مسبقًا إذا تطابق اسمها وقسمها.
- حقول شروط الاستفادة والمستندات والخطوات تُترك فارغة عمدًا إلى أن تتم مراجعتها من المصدر الرسمي.
- روابط المصادر في الدفعة الأولية تقود إلى بوابات وجهات رسمية ذات صلة، لكنها لا تعني أن كل تفاصيل كل سجل قد تم تدقيقها بعد.

## مبادئ أساسية
- التصفح والبحث دون اشتراط إنشاء حساب.
- عدم نشر معلومة أو شرط أو رسوم أو مستندات قبل مراجعة مصدر رسمي.
- كل خدمة منشورة يجب أن يكون لها مصدر رسمي وتاريخ مراجعة.
- أي تعديل على خدمة منشورة يعيدها إلى المسودات حتى تتم مراجعتها مرة أخرى.
- العربية واتجاه RTL افتراضيًا، مع مراعاة سهولة الوصول.

## لوحة الإدارة
المسار المحلي: http://localhost:5173/admin

يجب ضبط متغير البيئة `SANAD_ADMIN_TOKEN` في بيئة تشغيل الباك إند. لا تضع مفتاح الإدارة في الواجهة الأمامية أو في GitHub.
