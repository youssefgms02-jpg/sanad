# مراجعة مصادر الخدمات البنكية

## نطاق الدفعة
تضيف `backend/seed_banking_services.py` خمسين دليل خدمة بنكية منشورة في قسم `banking`. كل سجل يحدد البنك مقدم الخدمة ورابط صفحة البنك الرسمية التي تسرد الميزة الرقمية.

## المصادر الرسمية المستخدمة
- بنك مصر — خدمة الإنترنت والموبايل البنكي للأفراد: https://www.banquemisr.com/ar-EG/Pages/BM-Online---Internet-and-Mobile-banking
- QNB الأهلي — الخدمة المصرفية عبر الإنترنت: https://www.qnb.com.eg/sites/qnb/qnbegypt/page/ar/arinternetbankingservice.html
- NBK مصر — تطبيق الخدمات المصرفية عبر الهاتف المحمول: https://www.nbk.com/egypt/personal/ways-to-bank/mobile-banking-app.html

## ضوابط النشر
- تم قصر العناصر على ميزات وخدمات تسردها صفحات البنوك الرسمية.
- الرسوم، الحدود، أهلية العميل، التوافر، الموافقات، والعائد ليست ثوابت في دليل سَنَد؛ يجب مراجعتها داخل القناة الرسمية للبنك قبل تنفيذ أي طلب.
- لا يطلب سَنَد أرقام الحسابات أو البطاقات أو كلمات المرور أو رموز التحقق، ولا ينفذ تحويلات أو طلبات مالية.
- متطلبات المستندات قد تختلف حسب العميل والمنتج؛ لذلك يوجّه الدليل المستخدم إلى قناة البنك بدل اختراع قائمة مستندات موحدة.
- فحص الرابط أو وجوده لا يثبت وحده أن كل شرط تفصيلي صالح لكل عميل. يلزم تحديث المراجعة إذا عدّل البنك صفحة الخدمة أو شروطها.

## إعادة تشغيل الإدخال
من مجلد `backend`:
```powershell
.\.venv\Scripts\python.exe seed_banking_services.py
```
السكربت لا يكرر السجل الموجود بنفس الاسم داخل القسم، ويطبع عدد السجلات المنشورة ويتوقف بخطأ إذا كان العدد أقل من 50.
